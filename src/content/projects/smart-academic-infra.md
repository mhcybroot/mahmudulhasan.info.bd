# Smart Academic: Unified Micro-Frontend & Multi-Tier Campus ERP Infrastructure

> **At a Glance:** A unified, enterprise-grade academic administration, faculty payroll, student result tabulation, and executive portal monorepo engineered in Spring Boot 3.4, Java 21, Vue.js 3, and PostgreSQL 16. Smart Academic replaces fragmented, single-purpose campus software tools with an orchestrated micro-frontend ecosystem. Subsystems (Attendance & Shift Rostering, GPA Merit Compilation, Student Focus Telemetry, and Executive Analytics) are seamlessly unified under a modern glassmorphic dashboard with zero cross-origin styling friction and instant one-click deployment.

---

## 1. The Real-World Problem

In universities, polytechnic colleges, and educational groups across Bangladesh and internationally:

1. **Fragmented Software Silos:** Institutions run disconnected software tools—one PHP script for student attendance, separate desktop software for exam marksheets, an unintegrated accounting ledger for faculty payroll, and manual paper sign-in sheets. Staff must repeatedly re-enter student rosters, causing widespread human data entry errors.
2. **Clunky User Experience & Inconsistent UIs:** Academic staff and department deans are forced to juggle 4 to 5 different legacy web interfaces with contrasting designs, outdated layouts, and un-responsive tables that break on mobile devices.
3. **Severe Exam Tabulation Latency:** During semester finals, compiling student GPAs, semester credits, and merit standings across hundreds of course sections takes weeks of spreadsheet juggling, delaying transcript releases.
4. **Complex On-Premises Deployment Headaches:** University IT teams struggle with complicated server installation requirements, missing Java runtimes, unconfigured database connection pools, and conflicting node dependencies.

### The Smart Academic Solution
- **Unified Micro-Frontend Executive Portal:** A single-pane-of-glass Vue.js 3 & Vite dashboard that embeds independent Spring Boot backend modules inside sandboxed, dynamically themed iframes (`?embedded=true`), providing seamless single-sign-on navigation.
- **Project Loom High-Throughput Concurrency:** Utilizes Java 21 virtual threads in Spring Boot 3.4, enabling the attendance and result engines to process 5,000+ concurrent student queries without memory starvation.
- **Automated GPA & Grade Curve Tabulation:** Ingests internal marks, midterms, and finals into PostgreSQL, executing automated letter-grade mappings and credit-weighted GPA tabulation in sub-50ms.
- **Dynamic Cross-Origin Theme Interop:** Injects `smart-academic-theme.css` dynamically across all backend Thymeleaf templates, enforcing unified emerald-gold glassmorphic styles and hiding redundant server-side sidebars.
- **Zero-Dependency One-Click Deployment:** Features pre-packaged Windows and Linux orchestration scripts (`start_all.sh`, `package_windows.sh`, `setup_windows.bat`) bundling an embedded OpenJDK JRE, automated PostgreSQL schema migrations, and random mock data generators.
